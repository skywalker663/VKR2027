# Образовательная платформа геймификации образования

> Выпускная квалификационная работа — 2027

## 📌 О проекте

Проект представляет собой образовательную веб-платформу, использующую принципы **геймификации** для повышения вовлеченности учащихся в учебный процесс. 

Платформа объединяет в себе:
- Интерактивные **курсы для обучения**
- **Unity-игры** для практического закрепления материала
- **Граф выбора профессий** для профориентации школьников
- Личный кабинет ученика с элементами геймификации (баллы, достижения, уровни)

- Визуализацию **графа выбора профессий**
